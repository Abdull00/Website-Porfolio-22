## 🎨 Design Philosophy
This project focuses on a **Dark Luxury** aesthetic, utilizing:
* **Color Palette:** Deep Black (`#0B0B0F`), Charcoal (`#121218`), and Neon/Purple accents.
* **Visuals:** Glassmorphism, noise textures, and soft glow effects.
* **Interactions:** Smooth parallax scrolling, Arabic-to-English typing transitions, and motion-based reveals.

## 🛠️ Technical Stack
* **Frontend:** HTML5, CSS3 (Modern Flexbox/Grid)
* **Animations:** [AOS.js](https://michalsnik.github.io/aos/) (Animate on Scroll)
* **Typography:** [Typed.js](https://mattboldt.github.io/typed.js/) for the "السلام عليكم" hero experience.
* **Hosting:** GitHub Pages
